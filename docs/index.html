Modular Mechanics

Engineered For Performance

Every subsystem in simplecar2-rs operates as a decoupled, deterministic state machine ready for Bevy ECS and network rollback.

🛞

Raycast Suspension & ARBs

Simulates spring compression, bump & rebound damping, and anti-roll sway bar force transfer without expensive rigid body joint constraints.

$$F_N = k \cdot x - c \cdot v \pm k_{\text{arb}} \cdot (x_L - x_R)$$
⚡

Combustion & EV Drivetrains

Dual powertrain modes: accurate combustion engine RPM torque curves with rev limiters, or instant flat-torque electric motor profiles with regenerative braking.

$$P(t) = 0.3 + 0.7 \cdot t^2 \quad \text{for } RPM_{\text{idle}} \le RPM < RPM_{\text{peak}}$$
🕹️

Automatic Transmission

Multi-speed planetary or dual-clutch transmission with automatic upshift/downshift logic, rev-limiter safety overspeed shift, and shift torque cut.

$$R_{\text{total}} = R_{\text{gear}} \cdot R_{\text{final}}, \quad T_{\text{shaft}} = T_{\text{eng}} \cdot R_{\text{total}}$$
⚙️

Open, Locked & LSD Differentials

Configurable final drive split: 50/50 open differential, 100% spooled locked differential with normal load bias, or clutch-pack limited slip with speed delta lockup.

$$T_{\text{lock}} = \text{clamp}(k_{\text{lsd}} \Delta\omega + \text{sgn}(\Delta\omega) T_{\text{pre}}, -T_{\max}, T_{\max})$$
📐

True Ackermann Steering

Calculates exact distinct inner and outer wheel turn angles to trace concentric circles, with velocity-sensitive high speed steering lock reduction.

$$\delta_{\text{inner}} = \arctan\left(\frac{2L \tan\delta}{2L - W \tan\delta}\right)$$
🦀

Pure Rust & Zero Engine Lock-in

Built strictly on glam and serde. Easily drops into Bevy, Rapier, PhysX, or bespoke custom simulation pipelines with zero friction.

$$\text{glam::Vec3}, \quad \text{glam::Quat}, \quad \text{serde::Serialize}$$
Formulations

Mathematical Rigor

The analytical physics models underlying the simplecar2-rs implementation.

Anti-Roll Bar Dynamics

When cornering, centrifugal force produces chassis roll angle $\phi$, compressing the outer wheel ($x_{\text{outer}}$) and extending the inner wheel ($x_{\text{inner}}$). The sway bar creates equal and opposite corrective normal forces:

$$\Delta x = x_{\text{left}} - x_{\text{right}}$$ $$F_{\text{arb}} = k_{\text{arb}} \cdot \Delta x$$ $$F_{N,\text{left}} = F_{\text{spring}} + F_{\text{damping}} - F_{\text{arb}}$$ $$F_{N,\text{right}} = F_{\text{spring}} + F_{\text{damping}} + F_{\text{arb}}$$

Clutch Torque Coupling

Torque transfer between engine flywheel ($\omega_{\text{engine}}$) and transmission input shaft ($\omega_{\text{trans}}$) uses hyperbolic tangent friction smoothing:

$$T_{\text{capacity}} = \gamma \cdot T_{\text{max\_clutch}}$$ $$T_{\text{clutch}} = T_{\text{capacity}} \cdot \tanh\left(0.1 \cdot (\omega_{\text{engine}} - \omega_{\text{trans}})\right)$$
Integration

Quick Start Guide

Drop simplecar2 into your Cargo.toml and initialize your vehicle state machine in seconds.

Cargo.toml 
# Add to your dependencies
[dependencies]
simplecar2 = "0.1"
glam = "0.29"
main.rs 
use glam::{Quat, Vec3};
use simplecar2::prelude::*;

fn main() {
    // 1. Configure vehicle chassis, suspension & powertrain
    let mut vehicle = Vehicle::new(VehicleConfig::default());

    // 2. Supply driver inputs
    let inputs = VehicleInputs {
        steer: 0.25,        // Steer angle [-1.0, 1.0]
        throttle: 0.85,     // 85% throttle
        brake: 0.0,
        handbrake: false,
        clutch_pedal: 0.0,  // Clutch engaged
    };

    // 3. Provide raycast contact results from physics world (Rapier, XPBD, etc.)
    let hits = [
        Some(WheelRaycastHit { distance: 0.40, point: Vec3::new(-0.81, 0.0, 1.35), normal: Vec3::Y }),
        Some(WheelRaycastHit { distance: 0.40, point: Vec3::new(0.81, 0.0, 1.35), normal: Vec3::Y }),
        Some(WheelRaycastHit { distance: 0.40, point: Vec3::new(-0.81, 0.0, -1.30), normal: Vec3::Y }),
        Some(WheelRaycastHit { distance: 0.40, point: Vec3::new(0.81, 0.0, -1.30), normal: Vec3::Y }),
    ];

    // 4. Advance physics step
    let forces = vehicle.step(
        &inputs, hits,
        Vec3::new(0.0, 0.45, 0.0),
        Quat::IDENTITY,
        Vec3::new(0.0, 0.0, 14.0),
        Vec3::ZERO,
        1.0 / 60.0,
    ).unwrap();

    println!("Total force: {:?}", forces.total_force);
    println!("Engine RPM: {:.0}", vehicle.engine_state.rpm);
}
